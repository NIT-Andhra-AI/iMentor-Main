★ Worked Higher-Education Numerical Example & Step-by-Step Proof
Problem: Formulate the unilateral transform of the dynamic system response under critical damping conditions and verify asymptotic stability.

Analytical Solution:
1. Take the Laplace/Z-transform of governing differential equations.
2. Factorize the characteristic polynomial: $\Delta(s) = \det(s\mathbf{I} - \mathbf{A}) = 0$.
3. Apply partial fraction expansion and inverse transform to yield the closed-form time trajectory. $\blacksquare$

4. Assessment: Previous GATE Questions (2015–2024) with Detailed Solutions

📌 GATE NAT (2 Marks): In a 2nd-order unity feedback system with $G(s) = \frac{25}{s(s+6)}$, calculate the peak time $T_p$ in seconds for a unit step input.
Model Solution: Characteristic equation is $s^2 + 6s + 25 = 0 \implies \omega_n = 5\text{ rad/s}, \zeta = 0.6$. Damped frequency $\omega_d = \omega_n\sqrt{1-\zeta^2} = 5(0.8) = 4.0\text{ rad/s}$. Peak time $T_p = \frac{\pi}{\omega_d} = \frac{3.14159}{4.0} = \mathbf{0.785\text{ s}}$ (Tolerances: 0.77 to 0.80).
📌 GATE MCQ (2 Marks): A continuous-time LTI system with impulse response $h(t) = e^{-2t}u(t)$ is excited by $x(t) = u(t)$. The steady-state value of the output $y(\infty)$ is:
Model Solution: By the Final Value Theorem, $y(\infty) = \lim_{s\to 0} s Y(s) = \lim_{s\to 0} s \left(\frac{1}{s+2}\cdot \frac{1}{s}\right) = \frac{1}{2} = \mathbf{0.50}$.
